Turn what happened into Observations under the recording contract.

1. Find the direct demonstrations in the input: an answer, a worked step, an
   artifact section, a stated claim. Nothing for content merely touched.
2. Resolve each to exact node ids through provenance. Only nodes directly
   demonstrated; never prerequisites.
3. Payload: quote or reference what literally happened, with latency and the
   source's own judgment where present.
4. Interpretation: evidence kind (recognized, recalled, used, generalized,
   not-recalled) or mistake with coarseness (node, topic) and severity (slip,
   misconception, unknown). Node-coarse mistakes name what was confused
   with; misconceptions name the misconception. Support: unaided or guided
   when shown. Keyed choices never arrive here; they grade mechanically.
5. Emit one Observation per demonstration. Return nothing when nothing was
   demonstrated.
