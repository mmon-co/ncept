# Item authoring

Invoked at the first probe or first lesson on a node with an empty bank, or
front-loaded for threshold nodes. `(model)` Elicit the classic wrong
answers for the node's topic, then author at least one item matching its
criterion and knowledge type (factual: recall; conceptual:
misconception-mapped distractors; procedural: slip distractors). Each
multiple-choice option carries its default interpretation so grading is
mechanical. Multiple-choice hygiene: options of equal length, each
distractor a named error, skip means "I don't know". Every item must be
failable: name the wrong answer a real learner would give, or the item
confirms rather than measures. `(learner or author)` Reviews items for the
domain's actual misconceptions.
