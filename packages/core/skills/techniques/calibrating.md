# Techniques: calibrating

**Self-assessment is a hypothesis.**
When: the learner claims to know or not know something.
Do: record it as experience, use it to order probes, never record it as
evidence.
Evidence: fluency illusions; self-judged mastery tracks restudy fluency, not
storage (Bjork).

**Misconception-mapped distractors.**
When: authoring or choosing multiple-choice probes.
Do: make each distractor a named, classic wrong answer, so the choice itself
carries diagnostic information and grading is mechanical.
Evidence: concept inventories (Hestenes' FCI); BUGGY (Brown & Burton).

**Recognition ceiling.**
When: grading a commentless correct multiple-choice answer.
Do: record at most recognition-level evidence. Escalate format before
inferring more.
Evidence: recognition and recall are distinct retrieval strengths (memory
literature; the observation ladder).

**Format ladder.**
When: an answer strongly contradicts the current estimate, in either
direction, or a node is pinned at a rung's ceiling.
Do: escalate multiple choice to free response to assignment. Each rung buys
higher-fidelity evidence at higher cost.
Evidence: locally, the b5 design thread; generally, test-instruction
alignment moderates measured effects (Kulik & Fletcher 2016).
