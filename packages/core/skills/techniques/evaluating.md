# Techniques: evaluating

**Coverage is not learning.**
When: tempted to record evidence because material was presented.
Do: wait for a demonstration. Emit nothing for concepts merely touched.
Evidence: the storage/fluency distinction (Bjork); presentation predicts
little.

**Slips are random, bugs are systematic.**
When: classifying any mistake.
Do: distinguish slip from misconception; use unknown rather than inventing a
diagnosis. A repeated identical error is a bug, not a slip.
Evidence: Norman, Reason; VanLehn's repair theory.

**Corrected misconceptions are high-value records.**
When: a learner's wrong model gets fixed mid-session.
Do: record the misconception and its correction explicitly; it predicts
future stumbling blocks.
Evidence: conceptual-change literature (Chi, diSessa); also the teach-skill
precedent.
