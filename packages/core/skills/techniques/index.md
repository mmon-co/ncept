# Technique triggers

One line per technique in the library: the trigger, then the move. Full
entries with evidence live in the named section file. Question answering has
no Skill; it is opportunistic application of these triggers in any session.

Conducting ([conducting.md](./conducting.md)):

- No unaided success on this node or its siblings → worked example first.
- Guided successes accumulating → fade with competence, stepwise.
- Learner working a multi-step task → feedback at the step just taken.
- Conducting any practice → steer toward roughly 80% success.
- Session opens on previously seen content → retrieval opener, two or three
  recall questions, recorded as Observations.
- Scoping a session → single tangible win: one node, one nameable outcome.

Calibrating ([calibrating.md](./calibrating.md)):

- Learner claims to know or not know something → self-assessment is a
  hypothesis: record as experience, order probes with it, never as evidence.
- Authoring or choosing multiple-choice probes → misconception-mapped
  distractors.
- Grading a commentless correct multiple choice → recognition ceiling.
- Answer strongly contradicts the estimate, or a node pins at a rung → climb
  the format ladder.

Reviewing ([reviewing.md](./reviewing.md)):

- Scheduling retrievals → space them; never mass reviews of one node.
- Queue holds confusable categories → interleave within the session.
- Grading a timed retrieval → latency is signal; fast correct beats slow.

Authoring ([authoring.md](./authoring.md)):

- Inventorying nodes → a node is a measurement, not a topic.
- One topic yields "explain X" and "do X" → separate knowing from doing.
- A slice's shape is drafted → ground the graph in sources by search.
- Scoping a new mission's chart → slice before course, 10 to 25 nodes.
- Drafting or refining material → materials are criterion-delivery vehicles.
- Creating or revising a node → evidence before instruction: criterion and
  item before material.
- Proposing a dependency edge → definitional necessity, or no edge.
- Scoping a course → flag threshold concepts and budget extra there.
- Writing a criterion → one criterion per node; "and" splits the node.

Evaluating ([evaluating.md](./evaluating.md)):

- Tempted to record because material was presented → coverage is not
  learning; wait for a demonstration.
- Classifying a mistake → slips are random, bugs are systematic.
- A wrong model gets fixed mid-session → record the misconception and its
  correction.

Never ([do-not.md](./do-not.md)): learning styles; unassisted discovery for
novices; rereading or highlighting as practice; decorated materials; citing
2-sigma, 0.4–0.7 formative gains, or practice-makes-expert as magnitudes.
