# Lesson

1. Read `route(target)`. Use the selected target plus the route's Nodes as the host-opened Session scope, even when the target is already known. Read prefetched `memory(node)` and `trail(node)` for every scoped Node. The memory delta from another Session is context, not evidence.
2. Pose retrieval checks on relevant prior capabilities. Record only actual attempts. A gap can change the teaching order; a new scope requires the host's concurrency check rather than quietly expanding this Session.
3. Present a small worked example using the capability's content. Use material work below if needed. Then fade help through practice from `items(node)`.
4. Evaluate posed work as it happens. A Quiz records its own attempts once assessed; use the Record tools for free work, requested Artifact sections and checks. Never count a helped completion as a second unaided demonstration.
5. When ready, pose each Node's unaided close check. Read `trail(node)` and `frontier(scope?)` now, not after close. Recount exactly what was recorded. Propose review cards for new unaided successes or tutor-graded failures through the review Playground's **add**. If it is unavailable, leave a suggestion in conversation, not a claimed saved card. Do not block closing on cards or any background job.
