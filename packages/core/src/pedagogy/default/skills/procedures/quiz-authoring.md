Read `items(node)` before making a new task. An item is format-free content, not a new Node. Match the capability statement, not a taxonomy of formats.

Choose a task that a real learner could fail. Use competing wrong answers where keyed choice fits; optionally give each option an `error` string that preserves the actual mistake wording in the response. No fixed error taxonomy is required. A skip produces no Record. Decide unaided conditions before posing; choice on a production capability is aided even when mechanically correct.

Pose with the available task component or conversational check. The component appends its own demonstration, or evaluate free work with `record_demonstration`. Do not double-record. Saving an item bank is an approved host content edit, not an evidence write; without that affordance the item stays in conversation.
