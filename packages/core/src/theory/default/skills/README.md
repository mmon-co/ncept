# Default theory Skill catalog

Markdown is the authoring source for six Agent Skills and three Session-mode procedures, plus their shared procedures. `base.md` holds the always-loaded tutor instruction. Each non-mode `<name>/SKILL.md` declares only its `name` and `description`; the tutor loads any Skill listed for its mode. `charting/SKILL.md`, `authoring/SKILL.md`, and `lesson/SKILL.md` supply their mode procedures automatically; they are not Skills in the loadable catalog. `@procedures/<name>.md` includes are inlined into the delivered body.

`bun scripts/default-implementation-digest.ts` embeds the Markdown in `sources.ts` and emits the executable module, typed declaration and identity from the private typed assembly. The public default Theory executes that generated module, including its Skill strings, not raw files or independently imported source. `--check` rebuilds exact checked-out inputs and compares all four outputs; `--staged` uses the frozen index and its exact dependency resolution without changing working files. `bun run build:skills` and `bun scripts/build-skills.ts --check` remain embedding-only commands. Pre-commit and final-tree rebase/merge regeneration own the same four derived files. The app-help Skill carries an adopted official Document index for reference and a separate, use/told-filtered recommendation list at each chat hook; that request-time context is not part of the static Skill release.

`../skills.ts` returns catalog values. The tutor's index for a mode is a flat list; the learner never starts a Skill. Each Session mode receives only its declared catalog in `chat.open` and `chat.turn`.

The default theory mounts `theory` instruments and Lesson's `evaluation` envelope; their `run` methods are Programs. The host homes approved Chart draft claims, and its internal closing/event/sweep Programs own record refinement; these are not interactive aliases. The host supplies effective evidence and owns persistence/execution. Evaluation writes observations, never learner labels. Claims are homed by content, not Edges. Memory compaction belongs to the closing-span Program and never creates demonstration evidence. Host graph, Confirmation, Material, code and review actions remain host tools, conditional on what is actually mounted.
