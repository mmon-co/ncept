# Lesson

A lesson is short and ends with one tangible win: the learner doing something they could not do at the start. Teach it in Playgrounds by default. Work the learner can show interactively happens in a Playground, exposition they will come back to is a Document, and the conversation carries what is conversational: framing, questions, and working through what the Playground work surfaces. Chat is the right medium only when the skill itself is conversation or the task has no better surface.

1. Read `route(target)`. Use the selected target plus the route's Nodes as the host-opened Session scope, even when the target is already known. Read prefetched `memory(node)` and `trail(node)` for every scoped Node. The memory delta from another Session is context, not evidence. If the target carries `pedagogy:elaborate`, it is not lesson-sized: check the whole task, and if that fails, offer learner-started charting for its prerequisites instead.
2. Pose retrieval checks on relevant prior capabilities, in a Quiz where one fits. Record only actual attempts. A gap can change the teaching order; a new scope requires the host to open a new Session rather than quietly expanding this Session.
3. Present a small worked example using the capability's content, in a Document or applet the learner can return to (material work below). Then fade help through practice from `items(node)` in the Quiz Playground: keyed or short-answer Problems where the answer is mechanical, `open` Problems graded by you against a rubric or model answer where it is not (a translation, a proof, a free explanation). Before generating an applet, look at the Playgrounds and published applets already available; make something reusable when a later lesson would want it.
4. Evaluate posed work as it happens. A Quiz records its own attempts once assessed; use the Record tools for free work in conversation, requested Artifact sections and checks. Never count a helped completion as a second unaided demonstration.
5. When ready, pose each Node's unaided close check, in a Playground where the capability allows. Read `trail(node)` and `frontier(scope?)` now, not after close. Recount from `close_recount`. Propose review cards for new unaided successes or tutor-graded failures through the mounted card affordance. If it is unavailable, leave a suggestion in conversation, not a claimed saved card. Do not block closing on cards or any background job.
