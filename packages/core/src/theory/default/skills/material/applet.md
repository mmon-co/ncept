# applet

Kind: `applet`.

Create a applet Material; supply node or about, and list it without opening or focusing it. Applet metadata example: {"abi":"applet:1","libraries":{"@concept/applet":"1"},"queries":{"summary":"$.summary"},"commands":{"setPosition":{"inputSchema":{"type":"object","properties":{"fen":{"type":"string"}},"required":["fen"],"additionalProperties":false}}}}. The pinned runtime is resolved only in the mounted frame, not the tutor's shell; verify by opening the Material in the browser. Await `init()` before using `session`; use `initial.state` to restore and `state(value)` to persist. For a Node with an applet Material-scoped pedagogy:completion binding, use the existing emit({ kind: 'completion', node: nodeId, state: 'complete' | 'incomplete', validUntil?: ISO timestamp }) port. The host supplies reporter identity and provenance; ordinary emit payloads stay opaque. Completion changes acquisition, not recall scheduling. Always persist then post each move: await state(nextState); if (session) await session.post(move, { wake: helpEnabled }); quiet disables only wake, never the post. Use declared commands for live position/help changes; include reset or clear commands alongside placement commands for likely learner requests (for example, clear move history without changing the position). Implement and declare each command with its input schema; editing and reopening creates a new surface with separate state. A command call only queues work: the frame's result reaches you on a later turn, and delivery can repeat, so make the handler safe to replay with the command id. A post wakes the tutor only with { wake: true }, after await state(nextState); wakes share a 6-per-minute bucket and a rate-limited post is not retried later. Stop waking as help fades; keep posting. Adding only saves: material {kind:'applet',op:'open'} mounts the Material. Discover declared commands through read {resource:'applet',input:{surface,selection:{command}}} and queue them with material {kind:'applet',op:'command',command:<declared name>,input:{surface,arguments}}; no dynamically named command tools are mounted. An opening pins its revision, so editing the source and opening again is a new copy with separate state: say so, and restore the old position through a declared command. More runtime detail: packages/web/public/applet/README.md.
