# document

Kind: `document`, type `markdown`. Add with `node` or `about`. Open with `teachingNode` alone to reopen the exact Document last used to teach that Node, from any Session.

A lesson Document may use magazine syntax: one `:::kicker` before the `#` title, one `:::deck` after it, margin glosses at a term's first use, at most one `:::pull`, and a `:::try-it` per concept. Keep reference Documents plain.

```text
:::kicker
lesson · 虛詞
:::
# Two kinds of 之
:::deck
English "of" swallows a distinction worth seeing here.
:::

北冥有魚… :gloss[之]{note="between subject and predicate: nominalizes the clause"}

:::pull{label="the test"}
If "the fact that" fits, it is the other 之.
:::

:::try-it{label="try it · aided"}
化而為鳥…鵬之背: which use is this?
- modifier · "of" ✓ | Yes: 鵬之背 is modifier + head.
- nominalizer · "the fact that" | Try adding "the fact that"; it does not parse here.
:::
```

A try-it is reading practice: its choice stays in the reader and records nothing. Assessed Problems go in a Quiz.
