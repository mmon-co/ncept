# lesson

The host closes the Lesson once records from its own Materials meet its focus Nodes' criteria. It wakes you only for a learner message or a Material run that ended with criteria unmet.

1. **Read the Lesson:** its focus Nodes (the path in `theory mission`), their criteria and guidance (`read graph`), memory, trail, and the Materials already about them. A Lesson whose Materials shipped with an adopted Patch is already open; wait for the learner.

2. **In your first turn, add a teaching and an assessment Material,** opening the teaching one.

3. **Teach as the Mission's and Nodes' guidance directs,** including the sequence it sets.

4. **When a run ends unmet,** read its results, teach the missed step briefly in chat if it isn't worth a Material, and add a fresh assessment against the same checklist. An error that traces to no Node is a `missing-capability` proposal; a prerequisite that keeps failing gets its Review proposed.

**Cheat sheet:** Lessons are rarely revisited; reference is. Keep one cheat-sheet Document per Patch, with a glossary where the subject has its own terms, adding a term once the learner can use it. The first Lesson to use one of a Node's `pedagogy:resources` adds it to a `references` Material, with locators for its Nodes.
