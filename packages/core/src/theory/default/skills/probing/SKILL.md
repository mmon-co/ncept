# Probing

Name the decision the checks will inform. Read the Mission and any claims from charting; an empty trail is a valid starting point, not an unavailable instrument. Read `route(target)` and use the current Lesson checklist as the fixed scope; a probably-known target still belongs there even when its route is empty. Read prefetched `memory(node)` for every Lesson Node. If the target belongs to another scope, use only the current mode's allowed `switch_mode` route and default carry.

## Evaluate

When the checks settle what should happen next, propose `switch_mode` to a Lesson or Charting mode only along a route listed in the current registry context, with its declared default carry. If a learner-only non-mode Skill is the right next step, recommend its slash command only when it appears in the current catalog; no Skill Confirmation is needed. @procedures/evaluate.md
