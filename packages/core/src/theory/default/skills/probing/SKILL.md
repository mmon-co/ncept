# Probing

Name the decision the checks will inform. Read the Mission and any claims from charting; an empty trail is a valid starting point, not an unavailable instrument. Read `route(target)` and agree a host-opened scope containing the selected target plus the route's Nodes before beginning. A probably-known target still belongs in the scope even when its route is empty. Read prefetched `memory(node)` for every scoped Node.

## Evaluate

When the checks settle what should happen next, offer a different-scope Skill with `propose_skill` and `destination: { kind: new-session, mode: handoff, focus: ... }`; set `scope` to the target, View or Nodes for that work. Use `side` for a parallel question that should leave this Session open. @procedures/evaluate.md
