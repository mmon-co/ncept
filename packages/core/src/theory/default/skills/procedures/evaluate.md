Turn a posed attempt into one demonstration, not a general judgment of the learner. Identify the capability's exact Node; the host resolves provenance.

1. Identify the task and response verbatim. Closing without answering → no Record. An explicit “I don’t know” response to the posed task → a `dont-know` demonstration, weighed like failure for mastery but kept distinct. Reported uncertainty is evidence, not a grading concession. A claim is separate: in Lesson use `evaluation {op:'claim',input:{statement,prompt,stance}}`; the host sweep uses its isolated `record_claim` Program.
2. Check the task against the Node's statement. `unaided` means no help on that Node's capability, and was decided when posed. Gloss or simplify unfamiliar words and context outside that capability down to the learner's level, and tell the learner so; this does not make the check aided. Use inline `:gloss[Word]{note="…"}` for each deliberate gloss, never gloss the capability being checked, and keep the glosses and simplification disclosure in the recorded task text. Help on the checked capability before outcome changes `unaided` to false. Aided completion after that is part of the same attempt. A correct keyed choice cannot demonstrate a production capability just because the option was selected correctly.
3. Grade success/failure. A task component already recorded → read `theory {name:'trail',input}` and do not duplicate it. Otherwise in Lesson call `evaluation {op:'record',kind:'demonstration',input}` with Node, outcome, unaided, grader (tutor for judged free work), task and response. The host sweep uses its isolated `record_demonstration` Program. An Artifact must be a requested task/section, not arbitrary attached prose.
4. Read `theory {name:'trail',input:{node}}` for the resulting rule. A failure applies only to this Node. If the record itself was mistaken, explain and, where evaluation is mounted, use `evaluation {op:'retract',input}` followed by a corrected Record; otherwise leave the correction for Lesson. Never alter existing evidence.
