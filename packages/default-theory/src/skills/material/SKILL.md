Materials carry the learner into the work: worked examples, drills, structured checks, or briefs for real-world steps. Reuse existing Materials on a Node (`items`) before making new ones.

Prefer real-world, best-in-class tools when the real performance lives there (their editor, sketchbook, repo, DAW, real conversation) and judge the artifact rather than building a worse substitute. Keep Materials focused on criteria and practice—no decorative filler (seductive details).

A Material can teach, assess, or both, escalating difficulty and letting the learner retry until they clear the bar. Assess with unaided checks at the Nodes' criteria under Mission assessment guidance—enough independent checks to demonstrate each Node, graded mechanically wherever answers are mechanical. Once confusable skills are learned, interleave them in practice (not on first exposure).

- Lesson: [lesson.md](lesson.md) (and for a milestone, [milestone.md](milestone.md))

## Which Material

- **Document:** prose, worked examples, and reference worth revisiting.
- **Quiz:** graded tasks answered by choice, short/long text, code, applet, or roleplay—use for any posed check needing a verdict.
- **Code:** an interactive code workspace with files and tests (pose inside a Quiz to grade).
- **Applet:** a custom interactive environment (board, simulation, diagram) when no standard external tool fits (pose inside a Quiz to grade).
- **Roleplay:** a conversation with a character for interpersonal performances (pose inside a Quiz to grade).
- **Cards:** spaced-retention items for recall and fluency drills.
- **Reference:** a pointer to an outside book, course, or site located at the Nodes it teaches.
- **Audio:** generated speech for listening and spoken prompts.

## Assessing

- **Transfer-appropriate checks:** choices test recognition, so test production by having the learner produce. Give competing options similar length and form, and map distractors to specific misconceptions.
- **Granularity & feedback:** pose separate questions as separate short tasks. Give step-level feedback in practice; hold results until submission for prior-capability, retention, and milestone checks. Reserve an integrated response (explanation, essay, project) for showing several capabilities together, describing what a response visibly does so a grader can distinguish shown, absent, and mistaken.
- **Help & evidence:** in a Lesson, offer a hint after a mistake and add the correction if it persists; prior-capability, retention, and milestone checks only measure. One response counts once per Node regardless of how many checks touch it; when help touches a check, the Node is recorded unaided as it stood before help and aided as it ended.
