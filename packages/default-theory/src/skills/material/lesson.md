# lesson

The host closes the Lesson once its focus Nodes' completion queries hold over all evidence, including recorded reports of real steps. It wakes you only for a learner message or a Material run that ended with criteria unmet.

1. **Read the Lesson:** its focus Nodes (the path in `theory mission`), their criteria and guidance, memory, trail, and the Materials already about them. A Lesson whose Materials shipped with an adopted Patch is already open; wait for the learner.

2. **First turn: give the work and set completion.** For a real step, open a brief Material: what to do, what it serves (its dependents), what done looks like, and preparation that helps, such as working through a draft or rehearsing a conversation in a Roleplay. Set the Node's `pedagogy:completion` query to the evidence its criterion requires. The work itself is the check; the Lesson closes on the learner's report, recorded as `records` directs. Leave a return reminder through the host's mechanics. For exercise-based work, add teaching Material and one assessment set of short, single-question tasks, with `completion` queries for its focus Nodes sized to their criteria; end the teaching Document with `::next{id="<assessment set id>" title="<Set title>"}` and open only that Document: the learner opens the set from it.

3. **Teach as the Mission's and Nodes' guidance directs,** including the sequence it sets.

4. **When a run ends unmet,** read results, teach what's missed, and add new assessment items against the same checklist; rerun only assessments generating their own instances. An error that traces to no Node is a `missing-capability` proposal; a prerequisite that keeps failing gets its Review proposed.

**Cheat sheet:** Lessons are rarely revisited; reference is. Keep one cheat-sheet document per Patch, with a glossary where the subject has its own terms, adding a term once the learner can use it. The first Lesson to use one of a Node's `pedagogy:resources` adds it to a references Material, with locators for its Nodes.
