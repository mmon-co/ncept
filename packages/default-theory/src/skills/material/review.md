# review

Recheck due or fading Nodes in chat with fresh problems at their criteria; interleave confusable Nodes. Never replay an old Set as a recheck. For an `interval` Node, ask whether its criterion still holds and take the learner's word.

Give brief correctives on misses and reopen the Material that taught the Node. If a Node keeps coming due and has no queued Problem, write one (`srs` on hosts with Flashcards). Leave a collapsed prerequisite to the check-in to add a future Lesson; cleared Lessons stay cleared.
